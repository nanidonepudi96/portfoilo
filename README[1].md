# 🎓 Student Portfolio Website

A clean, responsive personal portfolio website built with **HTML** and **CSS**. It showcases my profile, skills, projects, and achievements in a single page.

## ✨ Features

- Responsive layout that works on mobile, tablet, and desktop
- Smooth-scrolling navigation
- Hero section with profile photo and call-to-action button
- Skills, projects, and achievements shown as cards
- Contact section with a "Send Email" button

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, gradients, media queries)

## 📂 Project Structure

```
├── index.html   # The complete portfolio page (HTML + CSS)
└── README.md    # Project documentation
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open the folder and double-click `index.html` to view it in your browser.

## 🌐 Live Demo (GitHub Pages)

1. Go to your repository's **Settings → Pages**.
2. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
3. After a minute, your site will be live at:
   `https://<your-username>.github.io/<your-repo-name>/`

## ✏️ Customization

- Replace the profile photo URL in the `.hero` section with your own image.
- Edit the About, Skills, and Projects text in `index.html`.
- Update the email and phone number in the Contact section.
- Change the theme colors in the `<style>` block (main colors: `#172554`, `#2563eb`, `#38bdf8`).
